SpyKit

HTTP Debugger & Security Toolkit

Inspect, debug, and manipulate HTTP traffic directly from Chrome DevTools.

  • Request/response inspector with search & regex
  • Security headers, CORS, cookies, secrets scanner
  • REST Client (GET/POST/PATCH + rate limiter)
  • Export: CURL, Python, JS, Go, Rust, PHP, HAR, CSV, Postman
  • Collections, workspaces, environment variables
  • Mock responses, domain blocking, request recording
  • Diff view, hex viewer, GraphQL detection
  • Bookmark/pin requests, snippets, dark/light theme
